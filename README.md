# Science Lab 🪐

> 읽는 과학 말고, 만져보는 과학.

물리·수학 공식을 코드로 옮겨 브라우저에서 직접 실험해 보는 사이트.

## 사실 이 프로젝트의 진짜 목적

겉으로는 과학 실험 사이트지만, 실은 **AI 에이전트 실험**이다.

> **목표: 이 사이트로 10만 원 벌기.**
> 그리고 Claude에게 "목표를 달성할 때까지 끊임없이 개선하고, 연구하고, 작업해 줘"라고 맡겼을 때
> **토큰을 효율적으로 쓰면서 스스로 판단해 일하는지**를 지켜본다.

궁금한 것들:
- 목표(수익)만 주면 에이전트는 무엇을 먼저 할까? 콘텐츠 품질? SEO? 엉뚱한 지름길?
- 사용량이 남아 있는 동안 쉬지 않고 일하게 하면, 그 토큰이 **의미 있는 개선**으로 바뀔까 아니면 제자리걸음에 타버릴까?
- 사람(나)은 텔레그램으로 지켜보다가 언제든 멈출 수 있다. 얼마나 자주 개입하게 될까?

규칙:
- 실험은 **3개로 고정**한다. 무한히 늘리는 게 아니라, 내가 공식을 이해할 수 있도록 **깊고 정확하게** 다듬는 쪽으로 일한다.
- 물리·수학이 틀리면 안 된다 → 모든 핵심 법칙을 테스트로 고정하고, CI를 통과해야만 배포된다.

전체 설계와 단계별 계획은 [PLAN.md](PLAN.md).

## 실험
| 실험 | 배우는 것 |
|---|---|
| [만유인력 태양계](experiments/solar-system/) | F = Gm₁m₂/r², 케플러 제3법칙 실시간 측정, 탈출 속도, 오일러 vs Velocity Verlet |
| [이중 진자와 카오스](experiments/double-pendulum/) | 라그랑지안 역학, RK4, 초기 조건 민감성, 리아푸노프 지수와 예측 가능 시간 |
| [푸리에 에피사이클](experiments/fourier/) | 오일러 공식, 이산 푸리에 변환, 파스발 정리, 깁스 현상, 직접 그린 그림 분해 |

각 실험 페이지 아래에는 **"공식 → 코드"** 섹션이 있어서, 공식이 실제 코드 몇 줄로 어떻게 옮겨지는지 따라갈 수 있다.

## 개발
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 물리·수학 테스트
npm run build   # dist/ 에 정적 사이트 생성
```

배포: `main`에 푸시하면 Netlify가 `npm test && npm run build`를 돌리고, 통과하면 배포한다.

## 테스트가 지키는 것
**태양계**: 10년 적분 후 에너지 오차 < 0.01% · 운동량 보존 · 지구 주기 1년 · 모든 행성 T²/a³ ≈ 1 · G×2 → 주기 ×1/√2 · 탈출 속도 = √2 × 원궤도 속도

**이중 진자**: 카오스 영역에서도 20초 에너지 오차 < 0.01% · 작은 각도에서 정규 모드 주기 = 이론값 · 큰 각도에서 10⁻⁹ rad 차이가 0.1 rad로 증폭 · 작은 각도에서는 증폭 안 됨

**푸리에**: 원 → k=1 계수 하나 · 전체 항으로 완전 복원 · 파스발 정리 · 항이 많을수록 오차 감소 · 리샘플링 등간격
