첫 진자와 마지막 진자의 차이

세로축은 로그 눈금. 직선으로 올라가면 지수적으로 벌어지는 중이라는 뜻이에요.

무슨 일이 일어나고 있나

1. 진자 하나는 얌전하다

길이 L인 진자의 각도 θ는 다음 방정식을 따릅니다.

θ'' = −(g / L) · sin θ

각도가 작으면 sin θ ≈ θ 이므로 θ'' = −(g/L)·θ, 즉 용수철처럼 일정한 주기 T = 2π√(L/g)로 흔들립니다. 언제 어디에 있을지 정확히 예측할 수 있죠.

2. 두 개를 이으면 방정식이 사나워진다

두 번째 진자는 첫 번째 진자 끝에 매달려 있어서, 서로가 서로를 잡아당기고 밀어냅니다. 이럴 때는 힘을 직접 따지는 것보다 에너지로 접근하는 게 편합니다. 운동에너지 T와 위치에너지 V를 쓰고,

T = ½(m₁+m₂)L₁²ω₁² + ½m₂L₂²ω₂² + m₂L₁L₂ω₁ω₂cos(θ₁−θ₂)
V = −(m₁+m₂)gL₁cos θ₁ − m₂gL₂cos θ₂

라그랑지안 ℒ = T − V에 오일러–라그랑주 방정식 d/dt(∂ℒ/∂ω) = ∂ℒ/∂θ을 적용하면 두 각가속도 θ₁'', θ₂''이 나옵니다. 식은 길지만(아래 코드 참고) 핵심은 하나예요: θ₁''이 θ₂와 ω₂에, θ₂''이 θ₁과 ω₁에 얽혀 있다는 것. 이 얽힘이 카오스의 씨앗입니다.

3. 결정론적인데 예측할 수 없다

이 시뮬레이션에는 무작위성이 전혀 없습니다. 같은 시작 → 항상 같은 결과. 그런데 시작 각도가 0.001°만 달라도, 몇 초 뒤엔 완전히 다른 곳에 있습니다. 이것이 카오스입니다.

패널의 그래프에서 두 진자의 차이 Δ는 대략 이렇게 자랍니다.

Δ(t) ≈ Δ₀ · e^(λt)   (λ: 리아푸노프 지수)

로그 눈금에서 직선으로 보이는 이유가 이것입니다. 직선의 기울기가 λ예요. 그러면 차이가 허용치 ε(여기선 0.1 rad)에 닿는 예측 가능 시간은

t* ≈ (1/λ) · ln(ε / Δ₀)

여기서 놀라운 결론이 나옵니다. 초기 오차 Δ₀를 1000배 줄여도 예측 가능 시간은 1000배가 아니라 ln(1000)/λ ≈ 6.9/λ만큼만 늘어납니다. 일기예보가 2주를 넘기기 어려운 이유도 같은 원리예요.

4. 왜 룽게–쿠타(RK4)를 쓰나

태양계에서는 Velocity Verlet을 썼지만, 이중 진자의 가속도는 각속도 ω에도 의존해서(ω² 항) 기본 Verlet을 그대로 쓸 수 없습니다. RK4는 한 스텝 안에서 기울기를 네 번(시작, 중간 두 번, 끝) 재서 가중 평균합니다. 오차가 dt⁴에 비례해서, dt = 1ms면 20초 동안 에너지 오차가 0.01%도 안 됩니다. 패널의 에너지 오차로 직접 확인해 보세요.

공식 → 코드

위의 운동방정식은 코드에서 이렇게 생겼습니다. den은 두 식에 공통으로 들어가는 분모예요.

// src/physics/pendulum.ts
const d = s.t1 - s.t2;
const den = 2*m1 + m2 - m2*Math.cos(2*d);

// θ₁'' : 중력 + 두 번째 진자가 끌어당기는 효과
const a1 = (-g*(2*m1+m2)*Math.sin(s.t1)
            - m2*g*Math.sin(s.t1 - 2*s.t2)
            - 2*Math.sin(d)*m2*(s.w2**2*L2 + s.w1**2*L1*Math.cos(d))) / (L1*den);

// θ₂'' : 첫 번째 진자의 원운동이 휘두르는 효과
const a2 = (2*Math.sin(d)*(s.w1**2*L1*(m1+m2)
            + g*(m1+m2)*Math.cos(s.t1)
            + s.w2**2*L2*m2*Math.cos(d))) / (L2*den);

// RK4: 기울기를 네 번 재서 1:2:2:1 로 평균
const k1 = f(s), k2 = f(s + k1·dt/2), k3 = f(s + k2·dt/2), k4 = f(s + k3·dt);
next = s + (k1 + 2k2 + 2k3 + k4)/6 · dt;

해볼 만한 실험

  • 작은 각도 10° + 진자 200개: 아무리 기다려도 한 덩어리로 움직입니다. 카오스는 큰 각도에서만 나타나요.
  • 예측 가능 시간 vs 초기 차이: 각도 차이를 10⁻³° → 10⁻⁶°로 1000배 줄이고 예측 가능 시간이 얼마나 늘어나는지 재보세요. 몇 배가 아니라 몇 초 늘어납니다.
  • g를 바꾸면: 달(1.62)에서는 모든 게 느려지지만 카오스는 그대로입니다. 예측 가능 "시간"은 길어질까요?
