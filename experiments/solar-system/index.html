케플러 제3법칙 측정

천체a (AU)T (년)T²/a³

이론값 T²/a³ = 4π²/(GM) = 1.000

무슨 일이 일어나고 있나

1. 모든 것은 한 줄의 공식에서

두 물체는 질량의 곱에 비례하고 거리의 제곱에 반비례하는 힘으로 서로를 끌어당깁니다.

F = G · m₁ · m₂ / r²

화면 속 모든 천체는 매 순간 다른 모든 천체로부터 이 힘을 받습니다. 태양만 행성을 당기는 게 아니라 행성도 태양을 당기고, 목성은 지구를 살짝 흔듭니다. 이 시뮬레이션은 그걸 전부 계산합니다(N체 문제).

2. 지구가 1년에 한 바퀴 돌도록 단위를 고르기

거리는 AU(지구–태양 거리), 시간은 년, 질량은 태양질량을 씁니다. 이 단위계에서는 중력 상수가 G = 4π² ≈ 39.48이 됩니다. 원궤도에서 중력이 구심력 역할을 하므로

G·M·m / r² = m·v² / r,   v = 2πr / T  ⟹  T² = (4π² / GM) · r³

r = 1 AU, M = 1 태양질량일 때 T = 1년이 나오려면 G = 4π²이어야 하죠. 이 마지막 식이 바로 케플러 제3법칙입니다. 측정 패널의 그래프에서 모든 행성이 기울기 1인 한 직선 위에 놓이는지 확인해 보세요.

3. 컴퓨터는 움직임을 어떻게 계산할까

컴퓨터는 연속적인 시간을 다룰 수 없어서, 아주 짧은 시간(여기서는 약 4.4시간)씩 끊어서 위치와 속도를 갱신합니다. 이 "끊는 방법"을 적분법이라고 합니다.

  • 오일러: "지금 속도로 dt만큼 가고, 지금 가속도로 속도를 바꾼다." 가장 직관적이지만, 매 스텝 오차가 한쪽으로 쌓여서 궤도가 조금씩 바깥으로 풀립니다. 에너지가 새는 거죠.
  • Velocity Verlet: 위치를 먼저 옮긴 뒤 옛 가속도와 새 가속도의 평균으로 속도를 갱신합니다. 계산량은 거의 같은데, 오차가 쌓이지 않고 출렁이기만 해서 수천 바퀴를 돌아도 궤도가 유지됩니다.

적분법을 오일러로 바꾸고 수성을 지켜보면서, 패널의 에너지 오차가 어떻게 커지는지 보세요.

공식 → 코드

F = Gm₁m₂/r²를 질량으로 나누면 가속도 a = Gm/r²가 되고, 방향은 상대 위치 벡터 (dx, dy)를 r로 나눈 단위 벡터입니다. 둘을 곱하면 G·m·dx / r³. 작용·반작용이라 한 쌍을 한 번만 계산해서 양쪽에 반대 부호로 더합니다. 

// src/physics/nbody.ts — 모든 쌍 (i, j)에 대해
const dx = b.x - a.x, dy = b.y - a.y;
const r2 = dx*dx + dy*dy + eps*eps;     // eps: r→0 에서 무한대 방지
const invR3 = 1 / (r2 * Math.sqrt(r2)); // 1/r³
a.ax += G * b.mass * dx * invR3;        // a가 b 쪽으로 끌림
b.ax -= G * a.mass * dx * invR3;        // b는 반대로 (뉴턴 제3법칙)

// Velocity Verlet 한 스텝
x += v*dt + ½·a_old·dt²;   // 1) 위치 이동
a_new = 가속도(x);          // 2) 새 위치에서 힘 계산
v += ½(a_old + a_new)·dt;  // 3) 두 가속도의 평균으로 속도 갱신

// 오일러는 1~3을 이렇게 뭉뚱그린다 → 에너지가 샌다
x += v*dt;  v += a_old*dt;

해볼 만한 실험

  • 탈출 속도: 지구를 공전 방향으로 원래 속도의 √2배(≈1.41배) 넘게 던지면 다시 돌아오지 않습니다.
  • G를 2배로: 궤도가 찌그러지고, 그래프의 직선이 아래로 내려갑니다. T²/a³ = 1/2이 되거든요.
  • 태양으로 던지기: 행성을 태양 쪽으로 세게 던지면 빨려 들어갑니다. 운동량은 태양이 이어받아요.
  • 오일러 + 빠른 시간: 수성이 나선을 그리며 바깥으로 도망가는 걸 볼 수 있어요.
